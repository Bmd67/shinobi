<div align="center">
  <h1>Shinobi (忍)</h1>
  <p><em>A stealthy Go microservice framework</em></p>
</div>

## Features
- High-performance Go HTTP server
- PostgreSQL with connection pooling
- Redis caching layer
- OpenTelemetry instrumentation
- Prometheus metrics
- Structured logging (zap)
- Graceful shutdown
- Multi-stage Docker build

## Quick Start
```bash
go run ./cmd/server
```
